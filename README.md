# Database Building
-- About:
Nesse projeto vamos gerenciar um banco de dados com Python, por meio dessa stack vamos estar enviando dados de uma API do BRASILAPI para alimentar o database e comandos SQL para gerenciar esse banco de dados.

-- How to run?
Para a execução desse teste recomendo que seja baixado o Visual Studio Code, sua IDE preferida ou Ferramentas online como Google Colab para a execução dos códigos em Python e para a execução dos códigos em SQL (aqui para fins de aprendizado usaremos a biblioteca sqlite3 para criação e gerenciamento do banco de dados criado).

-- Clone o repositório em sua máquina para melhor observação dos códigos. 

-- API utilizada para esse projeto nos retorna os dados diretos sem paginação, algo comum em algo api com a arquitetura REST, vamos trabalhar com as corretoras brasileiras, pois um mundo das finanças nos ensina muito sobre uma análise precisa e atenta dos dados.
